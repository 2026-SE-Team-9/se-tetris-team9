# SeoulTech SE Tetris — 9팀

서울과학기술대학교 소프트웨어공학 9팀의 Java 테트리스 프로젝트입니다.
일반 모드와 아이템 모드, 난이도 3단계, 색맹 모드, 키 설정, 모드별 스코어보드를 지원합니다.

| 항목 | 내용 |
|---|---|
| 언어 / UI | Java 21, Swing |
| 빌드 | Gradle (Wrapper 포함) |
| 테스트 | JUnit 5, JaCoCo (라인 커버리지 기준 50%) |
| 대상 OS | Windows 11 (실행 파일 패키징 기준) |
| 이슈 관리 | Jira + GitHub Issue |

---

## 실행 방법

### 배포 패키지로 실행 (권장)

Windows에서 아이콘이 포함된 실행 파일을 만듭니다. 패키지를 만드는 PC에는 JDK 21 이상이 필요하고, 패키지에 Java 실행 환경이 함께 들어가므로 실행하는 PC에는 Java가 없어도 됩니다.

```bash
.\gradlew.bat :tetris:jpackage
```

`tetris/build/jpackage/Tetris/Tetris.exe`를 더블클릭하면 실행됩니다.
다른 PC로 옮길 때는 `Tetris` 폴더 전체를 옮겨야 합니다.

### 소스에서 바로 실행

JDK 21 이상이 필요합니다.

```bash
# Windows
.\gradlew.bat :tetris:run

# macOS / Linux
./gradlew :tetris:run
```

## 화면 구성

| 화면 | 메뉴 | 이동 |
|---|---|---|
| 시작 메뉴 | 시작 · 아이템 모드 · 설정 · 스코어보드 · 종료 | **시작**은 일반 모드, **아이템 모드**는 아이템 모드로 게임을 시작합니다 |
| 게임 | — | `Esc`로 일시정지 메뉴를 엽니다. 블럭을 더 놓을 수 없으면 게임 종료 화면으로 넘어갑니다 |
| 일시정지 | 재개 · 설정 · 타이틀로 돌아가기 | 일시정지 중에는 게임 시간이 흐르지 않습니다 |
| 게임 종료 | 메인 메뉴 · 종료 | 최종 점수를 보여주고, 순위에 들면 이름을 입력받습니다 |

- 모든 화면은 키보드만으로 조작할 수 있습니다. 메뉴는 `↑` `↓`로 이동하고 `Enter`로 선택합니다.
- 게임 도중 종료하려면 `Esc` → **타이틀로 돌아가기** → 시작 메뉴의 **종료**를 선택합니다.

## 조작 키 (기본값)

| 동작 | 키 |
|---|---|
| 왼쪽 / 오른쪽 이동 | `←` / `→` |
| 아래로 한 칸 (소프트 드롭) | `↓` |
| 바로 떨어뜨리기 (하드 드롭) | `Space` |
| 시계 방향 회전 | `↑` 또는 `X` |
| 반시계 방향 회전 | `Z` |
| 일시정지 메뉴 | `Esc` |

조작 키는 **설정 → 조작 키**에서 바꿀 수 있으며, 키 하나를 두 동작에 중복으로 지정할 수는 없습니다.

## 게임 규칙

### 블럭

| 블럭 | I | O | T | S | Z | J | L |
|---|---|---|---|---|---|---|---|
| 칸 안 글자 | `I` | `O` | `T` | `S` | `Z` | `J` | `V` |

- 블럭마다 색과 글자가 모두 다릅니다. L형 블럭은 줄 삭제 아이템(`L`)과 겹치지 않도록 `V`로 표시합니다.
- 현재 블럭이 떨어질 위치를 흐린 `#`(고스트 블럭)로 미리 보여줍니다.
- 다음 블럭은 오른쪽 영역에 표시됩니다.

### 점수

| 항목 | 점수 |
|---|---|
| 블럭이 한 칸 떨어질 때마다 (자동·수동 무관) | 1 |
| 줄 삭제 (1 / 2 / 3 / 4줄 동시) | 100 / 300 / 600 / 1000 |
| 백투백 (4줄 동시 삭제를 연속으로 성공) | 2배 |

모든 점수에는 현재 레벨이 배율로 곱해집니다.

### 레벨과 속도

- `레벨 = max(삭제한 줄 수 / 10, 생성한 블럭 수 / 50) + 1`
- 레벨이 오를 때마다 낙하 간격이 줄어들며, 줄어드는 폭은 난이도마다 다릅니다 (하한 100ms).

### 난이도

난이도는 **시작 메뉴의 설정**에서 고르며, 일반 모드와 아이템 모드에 모두 적용됩니다.

| 난이도 | I형 블럭 등장 가중치 (다른 블럭 = 10) | 레벨당 낙하 간격 감소 |
|---|---|---|
| 쉬움 | 12 | 16% |
| 중간 (기본값) | 10 | 20% |
| 어려움 | 8 | 24% |

### 줄 삭제 애니메이션

줄이 지워질 때 해당 칸이 흰색으로 반짝인 뒤 사라집니다. 애니메이션 동안에는 게임이 잠시 멈추고 입력을 받지 않습니다.
아이템이 칸이나 줄을 지울 때도 같은 방식으로 표시됩니다.

## 아이템 모드

**10줄**을 지울 때마다 아이템 블럭이 등장합니다. 다음 블럭 영역에 이미 보이는 블럭은 바뀌지 않고, 그 다음 블럭이 아이템이 됩니다.
아이템은 5종 중 같은 확률로 선택됩니다.

| 글자 | 이름 | 형태 | 효과 |
|---|---|---|---|
| `L` | 줄 삭제 | 기본 블럭의 한 칸 | 블럭이 고정되면 `L`이 있는 줄을 바로 삭제합니다. 점수는 일반 줄 삭제와 같습니다. |
| `A` | 무게추 | 독립형, 위 2칸 · 아래 4칸 | 고정 전까지는 좌우로 움직일 수 있습니다. 고정되면 아이템 아래 칸을 바닥까지 모두 지운 뒤 보드에 남습니다. |
| `D` | Double or Nothing | 기본 블럭의 한 칸 | 보드에 남아 있다가 아이템이 포함된 줄이 꽉 차서 지워지면 그때의 삭제 점수가 **2배**가 됩니다. 다른 아이템에 지워지면 효과 없이 사라집니다. |
| `B` | Tall Boy | 독립형, 1×1 | 고정되면 아래로 2칸 파고든 뒤 자신을 중심으로 5×5 범위의 폭발을 일으킵니다. 폭발 범위 위쪽 블럭은 열마다 빈 공간만큼 아래로 떨어집니다. |
| `C` | Crusher | 독립형, 3×3 | 고정되면 자신 아래의 줄을 보드 맨 아래부터 최대 3줄까지 짓눌러 없애고, 자신은 보드에 남습니다. |

- `D`, `B`, `C`는 팀에서 설계한 아이템입니다. 점수, 10줄 카운트, 경계 상황을 포함한 상세 명세는 [2차 요구사항 문서의 「추가 아이템」](docs/requirements-2.md#추가-아이템)에 있습니다.
- 아이템 효과가 끝난 뒤 꽉 찬 줄이 추가로 생기면 일반 줄 삭제로 처리합니다.

## 설정

설정은 시작 메뉴와 일시정지 메뉴에서 열 수 있습니다. **저장**을 눌러야 반영되며, **취소**하면 이전 설정이 유지됩니다.

| 항목 | 선택지 | 비고 |
|---|---|---|
| 화면 크기 | 작게 / 보통 / 크게 | 게임 화면에 바로 적용 |
| 색맹 모드 | 켜기 / 끄기 | 게임 화면에 바로 적용 |
| 난이도 | 쉬움 / 중간 / 어려움 | 시작 메뉴에서만 변경 가능 |
| 조작 키 | 동작별 키 지정 | |
| 스코어보드 기록 초기화 | — | 시작 메뉴에서만 가능 |
| 모든 설정 기본값 | — | |

### 색맹 모드

색각이상(적색맹·녹색맹·청색맹)에서도 블럭과 아이템을 구분할 수 있도록 색표를 바꿉니다.

- 블럭 7종은 색각이상에서도 구분되도록 만든 **Okabe–Ito 팔레트**를 사용합니다.
- 블럭에 붙는 아이템 `L`·`D`는 진보라·진갈색으로, 모든 색각에서 다른 색과의 차이가 가장 크도록 골랐습니다.
- 독립형 아이템 `B`·`A`·`C`는 밝기만 다른 회색 3단계이며, 아이템 칸에는 안쪽 테두리가 그려집니다.
- 칸 안의 글자는 두 모드 모두 바탕색에 따라 검정과 흰색 중 잘 보이는 쪽으로 표시됩니다.

## 스코어보드

- 일반 모드와 아이템 모드의 기록을 **따로** 보관하며, 모드마다 상위 10개를 저장합니다.
- 기록마다 플레이한 난이도가 표시됩니다.
- 스코어보드 화면에서 `←` `→`로 모드를 전환합니다.
- 게임이 끝났을 때 상위 10위 안에 들면 이름을 입력해 기록을 등록합니다.

## 저장 파일

설정과 기록은 사용자 홈 폴더의 `.tetris` 폴더에 저장됩니다. 설정 파일이 없거나 값이 잘못되었으면 기본값으로 시작하고, 기록 파일은 손상된 줄만 건너뛰고 나머지를 불러옵니다.

| 파일 | 내용 |
|---|---|
| `~/.tetris/settings.properties` | 화면 크기, 색맹 모드, 난이도 |
| `~/.tetris/keybindings.properties` | 조작 키 |
| `~/.tetris/scores.csv` | 스코어보드 기록 |

Windows에서는 `C:\Users\<사용자 이름>\.tetris` 폴더입니다.

## 개발

### 테스트와 커버리지

```bash
# 단위 테스트 + 커버리지 보고서 (tetris/build/reports/jacoco/test/html/index.html)
.\gradlew.bat :tetris:test

# 라인 커버리지 50% 기준 검사
.\gradlew.bat :tetris:jacocoTestCoverageVerification
```

- PR마다 GitHub Actions가 테스트와 커버리지 검사를 실행하고, 실행 요약에 라인 커버리지를 표시합니다.
- 블럭 생성 확률은 실제 게임에서 쓰는 `BlockFactory`를 10만 회 실행해 가중치 대비 ±5% 이내인지 검증합니다.
- 아이템 효과와 애니메이션 상태는 모델에서 처리하므로 화면 없이 단위 테스트로 검증합니다.

### 구조

[계층 규칙](docs/project-conventions.md#8-계층-규칙)에 따라 모델은 화면을 모르고, 화면은 모델의 상태를 읽어 그리기만 합니다.

```
tetris/src/main/java/seoultech/se/tetris/
├── blocks/      블럭·아이템 종류, 모양, 칸 번호, 블럭·아이템 생성
├── engine/      보드, 게임 진행(TetrisEngine), 점수, 레벨, 난이도, 아이템 효과
├── component/   엔진과 화면 사이의 인터페이스 (상태 조회, 조작, 이벤트)
├── config/      설정·키 설정 저장
├── score/       스코어보드 저장
└── ui/          Swing 화면 (메뉴, 게임, 일시정지, 설정, 스코어보드, 게임 종료)
```

새 아이템은 `ItemType`에 종류와 모양을 추가하고, `ItemEffect` 인터페이스를 구현해 `ItemEffects`에 등록하면 됩니다. `TetrisEngine`은 수정하지 않아도 되며, 등록을 빠뜨리면 컴파일 오류가 납니다.
