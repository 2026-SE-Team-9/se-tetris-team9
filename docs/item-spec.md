# 아이템 요구사항 명세서

> 2차 요구사항(아이템 모드)의 아이템 5종을 요구사항 명세 형식으로 정리한 문서다.
> 아이템의 규칙 자체는 [2차 요구사항 문서](requirements-2.md)의 「아이템 등장」~「아이템 모드 관련 추가사항」과 같으며,
> 이 문서는 그 내용을 **검증할 수 있는 요구사항 단위**로 나누고 각 요구사항을 확인하는 테스트와 연결한다.

---

# 1. 개요

## 범위

| 아이템 | 문자 | 출처 |
|---|---|---|
| 줄 삭제 | `L` | 원문 제시 + 팀 결정 |
| 무게추 | `A` | 원문 제시 + 팀 결정 |
| Double or Nothing | `D` | 팀 설계 |
| Tall Boy | `B` | 팀 설계 |
| Crusher | `C` | 팀 설계 |

원문 제시 아이템도 점수·10줄 카운트 등 팀이 정한 규칙이 있으므로 함께 명세한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 포함형 아이템 | 기본 블럭의 한 칸에 붙어서 나오는 아이템 (`L`, `D`) |
| 독립형 아이템 | 기본 블럭 대신 아이템 자체가 하나의 블럭으로 나오는 아이템 (`A`, `B`, `C`) |
| 고정 | 블럭이 바닥이나 다른 블럭에 닿아 더 내려갈 수 없게 되어 보드에 놓이는 것. 하드 드롭도 포함한다 |
| 일반 줄 삭제 | 꽉 찬 줄을 지우는 기본 규칙. 줄 삭제 점수·10줄 카운트·백투백에 반영된다 |
| 줄 삭제 애니메이션 | 지워질 칸을 깜빡여 보여 주는 동안 게임을 멈추는 연출. 아이템이 칸·줄을 지울 때도 같은 방식으로 멈춘 뒤 처리한다 |
| 10줄 카운트 | 아이템 등장과 레벨 상승의 기준이 되는 누적 삭제 줄 수 |
| 백투백 | 4줄 동시 삭제를 연속으로 성공하면 점수를 2배로 하는 규칙 (1차 요구사항) |
| 레벨 배율 | 현재 레벨에 따라 점수에 곱하는 값 (1차 요구사항) |

## 요구사항 표기

- **ID**: `IR-<구분>-<번호>`. 구분은 공통 `00`, 그 밖에는 아이템 문자(`L`, `A`, `D`, `B`, `C`)
- **요구 수준**: "~해야 한다"는 필수, "~하는 것이 좋다"는 권장
- **유형**: 기능 / 비기능
- **근거**: `원문`은 원문 요구사항, `팀`은 팀 결정. 팀 결정 중 이유가 있는 것은 이유를 함께 적는다
- **확인 테스트**: `테스트 클래스 › 묶음 › 테스트 이름` (테스트 이름은 `@DisplayName`). 아직 테스트가 없는 요구사항은 **보완 예정**으로 표시한다

## 아이템별 구성

각 아이템은 다음 순서로 명세한다.

1. **사용자 요구사항**: 게임을 하는 사람 입장에서 아이템이 무엇을 하는지 한두 문장
2. **시스템 요구사항**: 기능 / 설명 / 사전 조건 / 입력 / 동작 / 사후 조건 / 부작용 양식
3. **요구사항 표**: 검증 단위로 나눈 요구사항과 근거, 확인 테스트
4. **조건별 동작**: 상황에 따라 동작이 갈리는 경우를 조건 → 동작 표로 정리
5. **관련 요구사항**: 이 아이템과 맞물리는 다른 요구사항

# 2. 공통 요구사항

## 시스템 요구사항

| 항목 | 내용 |
|---|---|
| 기능 | 아이템 등장과 공통 처리 |
| 설명 | 아이템 모드에서 줄을 지울 때마다 정해진 간격으로 아이템 블럭을 내보내고, 모든 아이템에 같은 표시·처리 규칙을 적용한다 |
| 사전 조건 | 시작 메뉴에서 아이템 모드를 선택해 게임이 진행 중이다 |
| 입력 | 줄 삭제(일반 줄 삭제 또는 줄 삭제 아이템)로 누적 삭제 줄 수가 10의 배수를 넘김 |
| 동작 | 아이템 5종 중 하나를 균등한 확률로 골라 다다음 블럭을 아이템 블럭으로 만든다 |
| 사후 조건 | 다다음 블럭이 아이템 블럭이거나 아이템이 붙은 블럭이다. 이미 다음 블럭 영역에 보이는 블럭은 그대로다 |
| 부작용 | 없음 |

## 요구사항 표

| ID | 요구사항 | 유형 | 근거 | 확인 테스트 |

| IR-00-02 | 누적 삭제 줄 수가 10줄 단위를 넘길 때마다 아이템이 등장해야 한다. 여러 줄을 한 번에 지워 단위를 넘긴 경우(예: 9줄 → 12줄)도 포함한다 | 기능 | 원문 + 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 아이템 모드에서 10줄을 넘기면 다다음 블럭이 아이템 블럭이 된다` |
| IR-00-03 | 10줄 단위를 채운 블럭의 **다다음 블럭**이 아이템 블럭이 되어야 하며, 이미 다음 블럭 영역에 표시 중인 블럭은 바꾸지 않아야 한다 | 기능 | 원문 — "다음 블럭 표시 영역에 **새로 나타나는** 블럭은 아이템이거나 아이템을 포함해야 한다". 새로 나타나는 블럭이 다다음 블럭이다 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 다음 블럭 영역에 이미 보이던 블럭은 바꾸지 않는다` |
| IR-00-04 | 아이템은 5종 중 균등한 확률로 골라야 한다 | 기능 | 팀 — 원문에는 아이템을 고르는 확률이 정해져 있지 않다 | `ItemFactoryTest › 확률 (시행 10만 회, 상대 오차 ±5%) › 아이템 5종이 균등한 확률로 나온다` |
| IR-00-05 | 포함형 아이템은 원래 다다음 블럭이던 테트로미노에 붙어야 한다 | 기능 | 원문 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 포함형 아이템은 원래 다다음 블럭이던 테트로미노에 붙는다` |
| IR-00-06 | 아이템 블럭도 기본 블럭과 같은 생성 위치에서 등장해야 한다 | 기능 | 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 아이템 블럭도 생성 위치에서 등장한다` |
| IR-00-07 | 아이템은 아이템끼리, 그리고 기본 블럭·고스트 블럭과 서로 다른 문자로 표시해야 한다 | 기능 | 원문 | `ItemTypeTest › 표시 문자와 번호 › 아이템끼리, 그리고 기본 블럭·고스트와 문자가 겹치지 않는다` |
| IR-00-08 | 아이템이 칸이나 줄을 지울 때는 줄 삭제 애니메이션과 같은 방식으로 게임을 멈춘 뒤 처리해야 한다 | 기능 | 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 무게추: …` (고정 직후 애니메이션 상태가 되고 지워질 칸이 표시되는지 확인), `TetrisEngineTest › 줄 삭제·백투백·레벨 › 애니메이션 동안에는 일시정지를 포함한 모든 조작을 무시한다` 외 아이템별 효과 테스트 |
| IR-00-09 | 10줄 카운트에는 일반 줄 삭제와 줄 삭제 아이템(`L`)으로 지운 줄만 포함해야 한다. 무게추·Tall Boy·Crusher가 지운 칸·줄은 포함하지 않아야 한다 | 기능 | 팀 | 각 아이템의 요구사항 표 참고 (IR-L-07, IR-A-07, IR-B-09, IR-C-06) |
| IR-00-10 | 아이템 블럭이 생성 위치에 놓일 수 없으면 기본 블럭과 같이 게임을 종료해야 한다. 애니메이션 도중 종료 조건이 생기면 애니메이션을 마친 뒤 종료해야 한다 | 기능 | 팀 — 1차 게임 종료 규칙과 충돌하지 않도록 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 아이템 블럭이 생성 위치에 놓일 수 없으면 게임을 종료한다`, `TetrisEngineTest › 줄 삭제·백투백·레벨 › 애니메이션 도중 게임 종료 조건이 생기면 애니메이션을 마친 뒤 종료한다` |
| IR-00-11 | 색맹 모드에서도 아이템을 구분할 수 있어야 한다. 아이템 칸은 고유 문자와 안쪽 테두리로 표시한다 | 비기능 (사용성) | 원문 (1차 색맹 모드와의 관계) + 팀 (안쪽 테두리, 3차 요구사항) | `BlockPaletteTest › 테두리는_색맹_모드의_아이템_칸에만_있다`, `BlockPaletteTest › 색맹_모드의_색은_모두_다르고_깜빡임_색인_흰색을_쓰지_않는다` |
| IR-00-12 | 아이템을 새로 추가할 때 엔진을 고치지 않고 아이템 동작만 추가할 수 있는 구조여야 한다 | 비기능 (유지보수성) | 원문 | `ItemEffectTest › 아이템마다 동작이 연결되어 있고, 아이템이 없으면 일반 블럭 동작이다` |

## 조건별 동작

| 조건 | 동작 |
|---|---|
| 일반 모드에서 10줄 단위를 넘김 | 아이템이 등장하지 않는다 |
| 아이템 모드에서 한 번에 여러 줄을 지워 10줄 단위를 넘김 | 한 번만 등장한다 (예: 9줄 → 12줄) |
| 다다음 블럭이 될 블럭이 테트로미노이고 포함형 아이템이 뽑힘 | 그 테트로미노의 한 칸에 아이템이 붙는다 |
| 독립형 아이템이 뽑힘 | 다다음 블럭이 아이템 블럭으로 바뀐다 |
| 대전 모드에서 아이템 칸이 있는 줄을 공격으로 보냄 | 보낸 줄의 칸은 모두 공격 칸으로 대체되어 아이템 효과가 없다 (3차 요구사항) |

## 관련 요구사항

- 1차: 게임 종료, 색맹 모드, 화면 크기(아이템 문자도 칸 크기에 맞춰 표시)
- 2차: 줄 삭제 애니메이션, 난이도
- 3차: 대전 모드의 줄 공격 (아이템별 공격 규칙은 각 아이템의 조건별 동작 참고)

# 3. 아이템별 명세

## 3.1 줄 삭제 (`L`)

### 사용자 요구사항

블럭에 붙은 `L`이 있는 줄은 블럭을 놓는 순간 꽉 차지 않았어도 지워진다.

### 시스템 요구사항

| 항목 | 내용 |
|---|---|
| 기능 | 줄 삭제 |
| 설명 | `L`이 붙은 블럭이 고정되면 `L`이 있는 줄을 꽉 찬 줄과 함께 줄 삭제로 지운다 |
| 사전 조건 | 아이템 모드이며, 현재 블럭의 한 칸에 `L`이 붙어 있다 |
| 입력 | 현재 블럭의 고정 |
| 동작 | `L`이 있는 줄과 꽉 찬 줄을 모아(겹치는 줄은 한 번만) 줄 삭제 애니메이션 뒤 지우고, 지운 줄 수로 줄 삭제 점수를 계산한다 |
| 사후 조건 | 지운 줄 위의 블럭이 내려오고, 점수와 누적 삭제 줄 수가 늘어난다. 보드에 `L`은 남지 않는다 |
| 부작용 | 10줄 단위를 넘기면 아이템이 등장하고 레벨이 오를 수 있다. 대전 모드에서는 공격이 생길 수 있다 |

### 요구사항 표

| ID | 요구사항 | 유형 | 근거 | 확인 테스트 |
|---|---|---|---|---|
| IR-L-01 | 기본 블럭 안에 포함되는 아이템이며, 문자 `L`로 표시해야 한다 | 기능 | 원문 | `ItemTypeTest › 형태 › 줄 삭제와 Double or Nothing만 블럭에 붙는 포함형이다`, `ItemTypeTest › 표시 문자와 번호 › 요구사항 문서의 아이템 문자표대로 표시한다` |
| IR-L-02 | 블럭에 붙는 위치는 블럭의 4칸 중 무작위여야 한다 | 기능 | 원문 | `ItemFactoryTest › 확률 (시행 10만 회, 상대 오차 ±5%) › 포함형 아이템은 블럭의 4칸에 균등한 확률로 붙는다` |
| IR-L-03 | 블럭이 회전해도 `L`은 같은 칸에 붙어 있어야 한다 | 기능 | 팀 | `BlockTest › 포함형 아이템 › 회전하면 붙은 칸도 같은 칸을 따라간다` |
| IR-L-04 | 블럭이 고정되면 줄이 꽉 찼는지와 관계없이 `L`이 있는 줄을 지워야 한다 | 기능 | 원문 | `ItemEffectTest › 줄 삭제 (L) › 꽉 차지 않아도 L이 있는 줄을 지운다`, `TetrisEngineTest › 줄 삭제·백투백·레벨 › 줄 삭제 아이템: 꽉 차지 않은 줄도 지우고 줄 삭제로 점수와 줄 수를 반영한다` |
| IR-L-05 | `L`이 있는 줄이 꽉 찬 줄이기도 하면 일반 줄 삭제로 한 번만 지워야 한다 | 기능 | 팀 — 같은 줄을 두 번 세지 않도록 | `ItemEffectTest › 줄 삭제 (L) › L 줄이 꽉 찬 줄이기도 하면 한 번만 지운다` |
| IR-L-06 | 점수는 `L` 줄과 꽉 찬 줄을 합친 총 삭제 줄 수로, 기존 줄 삭제 점수 방식대로 계산해야 한다 | 기능 | 원문 + 팀 | `ItemEffectTest › 줄 삭제 (L) › L 줄과 다른 꽉 찬 줄을 합쳐서 지운다`, `TetrisEngineTest › 줄 삭제·백투백·레벨 › 줄 삭제 아이템: …` |
| IR-L-07 | `L`로 지운 줄은 10줄 카운트에 포함해야 한다 | 기능 | 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 줄 삭제 아이템: …` (삭제 줄 수 1 확인) |
| IR-L-08 | 고정 즉시 지워지므로 보드에 `L`이 남지 않아야 한다 | 기능 | 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 줄 삭제 아이템: …` (지운 칸이 빈 칸인지 확인) |
| IR-L-09 | 하드 드롭은 일반 블럭과 같아야 한다 | 기능 | 팀 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › 줄 삭제 아이템: …` (하드 드롭으로 18칸 낙하 점수를 얻고 바닥에 고정되는지 확인) |

### 조건별 동작

| 조건 | 동작 |
|---|---|
| `L` 줄이 꽉 차지 않음 | `L` 줄을 지운다. 1줄 삭제 점수 |

### 관련 요구사항

## 3.2 무게추 (`A`)

## 3.3 Double or Nothing (`D`)

### 사용자 요구사항

블럭에 붙은 `D`는 보드에 남아 있다가, 그 줄을 꽉 채워 지우면 점수를 2배로 준다. 다른 아이템에 지워지면 아무 효과 없이 사라진다.

### 시스템 요구사항

| 항목 | 내용 |
|---|---|
| 기능 | Double or Nothing |
| 설명 | `D`가 있는 줄이 꽉 찬 줄로 지워지면 그 줄 삭제의 최종 점수를 2배로 한다 |
| 사전 조건 | 아이템 모드이며, 보드에 `D`가 놓여 있다 |
| 입력 | `D`가 있는 줄의 삭제 |
| 동작 | 꽉 찬 줄로 지워지면 레벨 배율과 백투백을 적용한 최종 점수를 2배로 한다. 그 밖의 아이템에 지워지면 가산하지 않는다 |
| 사후 조건 | `D`가 보드에서 사라진다 |
| 부작용 | 없음 |

### 요구사항 표

|---|---|---|---|---|
| IR-D-01 | 기본 블럭 안에 포함되는 아이템이며, 문자 `D`로 표시해야 한다. 붙는 위치는 블럭의 4칸 중 무작위여야 한다 | 기능 | 팀 | `ItemTypeTest › 형태 › 줄 삭제와 Double or Nothing만 블럭에 붙는 포함형이다`, `ItemFactoryTest › 확률 (시행 10만 회, 상대 오차 ±5%) › 포함형 아이템은 블럭의 4칸에 균등한 확률로 붙는다` |

## 3.4 Tall Boy (`B`)

### 사용자 요구사항

1칸짜리 `B`가 놓이면 아래로 두 칸 파고들어 주변 5×5 범위의 블럭을 날려 버리고 자신도 사라진다.

| 항목 | 내용 |
|---|---|
| 기능 | Tall Boy |
| 설명 | 고정되면 아래로 최대 2칸 파고든 위치를 중심으로 5×5 범위의 블럭을 지우고, 그 위쪽 블럭을 내린다 |
| 사전 조건 | 아이템 모드이며, 현재 블럭이 Tall Boy다 |

| 사후 조건 | Tall Boy는 보드에서 사라진다. 떠 있는 블럭이 남지 않는다. 내려온 블럭이 줄을 채우면 일반 줄 삭제가 이어진다 |

| IR-B-06 | 폭발 범위 위쪽의 블럭은 열마다 한 덩어리로, 아래 블럭이나 바닥에 닿을 때까지 내려와야 한다 | 기능 | 팀 — 떠 있는 블럭이 남지 않도록 | `TetrisEngineTest › 줄 삭제·백투백·레벨 › Tall Boy: 폭발 범위 위쪽의 블럭은 떠 있지 않고 아래가 막힐 때까지 내려온다` |

| IR-B-08 | 점수는 블럭이 있던 칸 수 × 10점에 레벨 배율을 적용해야 한다. 자신의 칸도 포함하며, 파고든 자리와 겹쳐도 한 번만 센다 (최대 250점) | 기능 | 팀 — 자신의 칸은 자신도 사라지는 아이템이기 때문에 포함한다 | `ItemEffectTest › Tall Boy (B) › 2칸 파고든 뒤 5×5 범위의 …`, `TetrisEngineTest › 줄 삭제·백투백·레벨 › Tall Boy: 파고든 자리 중심 5×5를 …` |

### 조건별 동작

| 조건 | 동작 |
|---|---|
| 바닥까지 2칸 이상 남음 | 2칸 파고든 뒤 폭발 |
| 바닥까지 2칸 미만 | 갈 수 있는 만큼 파고든 뒤 폭발 |
| 5×5 범위가 벽이나 바닥 밖으로 나감 | 보드 안쪽만 지운다 |
| 5×5 범위에 빈 칸이 있음 | 빈 칸은 점수에 넣지 않는다 |

| 내려온 블럭이 줄을 채움 | 일반 줄 삭제가 이어진다 |
| 대전 모드에서 Tall Boy 효과로 줄이 채워짐 | 공격하지 않는다 (3차 요구사항). 폭발 뒤 위쪽 블럭이 내려오는 것까지 Tall Boy의 효과이고, Tall Boy는 효과와 함께 사라지므로 그 줄은 Tall Boy 자신이 채운 줄이 아니다. 2줄 이상이 채워져도 같다 (`TetrisEngineVersusTest › 공격 만들기 › Tall Boy 폭발 뒤 내려온 블럭이 2줄 이상을 채워도, Tall Boy는 사라졌으므로 공격하지 않는다`) |

### 관련 요구사항

- IR-00-08 (멈춘 뒤 처리), IR-00-09 (10줄 카운트), IR-D-06 (`D`가 Tall Boy에 지워질 때)
- 1차: 점수 계산(레벨 배율, 백투백)

## 3.5 Crusher (`C`)

### 사용자 요구사항

3×3 크기의 `C`가 놓이면 그 아래의 줄을 바닥부터 최대 3줄까지 짓눌러 없애고 그만큼 내려앉는다.

### 시스템 요구사항

| 항목 | 내용 |
|---|---|
| 기능 | Crusher |
| 설명 | 고정되면 자신 아래의 줄을 보드 맨 아래부터 최대 3줄 통째로 지우고, 지운 줄 수만큼 위의 줄(자신 포함)을 내린다 |
| 사전 조건 | 아이템 모드이며, 현재 블럭이 Crusher다 |
| 입력 | 현재 블럭의 고정 |
| 동작 | 게임을 멈춘 상태에서 자신 아래에 있는 줄을 맨 아래부터 최대 3줄 지우고 위의 줄을 내린다. 점수는 주지 않는다 |
| 사후 조건 | Crusher가 보드에 남는다. 내려온 줄이 채워지면 일반 줄 삭제가 이어진다 |
| 부작용 | 짓누른 줄은 줄 삭제가 아니므로 10줄 카운트와 백투백에 영향을 주지 않는다 |

### 요구사항 표

| ID | 요구사항 | 유형 | 근거 | 확인 테스트 |
|---|---|---|---|---|
| IR-C-01 | 3×3 크기의 사각형 독립형 아이템이며, 문자 `C`로 표시해야 한다 | 기능 | 팀 | `ItemTypeTest › 형태 › Crusher는 3×3 사각형이다`, `ItemTypeTest › 표시 문자와 번호 › 요구사항 문서의 아이템 문자표대로 표시한다` |

### 조건별 동작

| 조건 | 동작 |
|---|---|
| 아래에 줄이 3줄 이상 | 맨 아래 3줄을 지우고 3줄 내려앉는다 |
| 아래에 줄이 1~2줄 | 있는 만큼 지우고 그만큼 내려앉는다 |
